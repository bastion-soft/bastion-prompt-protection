# Evaluation

Reproducible benchmark harness for scoring `bastion_prompt_protection.Guard` (and competing models) against held-out public datasets. The numbers in the repo README and on the model card are generated by these scripts; clone the repo and re-run to verify any claim.

## Held-out benchmarks

| Benchmark | Source | n | Notes |
|---|---|---|---|
| `rogue` | `rogue-security/prompt-injections-benchmark` | 5,000 | Long, narrative-wrapped attacks |
| `xtram1_test` | `xTRam1/safe-guard-prompt-injection` test split | 2,060 | Standard injection, held out from training |
| `slabs_test` | `S-Labs/prompt-injection-dataset` test split | 2,101 | Security-lab curated, held out from training |
| `jailbreakbench` | `JailbreakBench/JBB-Behaviors` | 200 | Harmful-behavior elicitation |

All four were excluded from the bastion training corpus.

## Headline metrics

| Metric | Why it matters |
|---|---|
| AUC | Threshold-independent ranking quality |
| F1 @ 0.5 | Practical default-threshold quality |
| FPR @ TPR=0.99 | False-positive rate at high recall — the deployment-critical number |
| p50 / p95 latency | Adoption gate; bastion ships sub-10 ms p50 |

## Running the full leaderboard

Reproduces the comparison table in the repo README — bastion against four public baselines, across all four held-out benchmarks. Writes JSON + Markdown to `eval/results/`.

```bash
pip install -e ".[eval]"
python -m scripts.run_leaderboard
```

Wall-clock: ~10 minutes on a GPU, ~30 minutes on CPU. The script is idempotent — re-run any time to refresh the numbers.

## Single-runner mode

For scoring one model against the suite (e.g. a freshly-trained checkpoint, or any baseline of your choice):

```bash
# Score the published bastion model against all four benchmarks
python -m eval.benchmark_suite --runner bastionsoft/binary-bastion-prompt-protection-deberta-v3-xsmall-v1

# Score a locally-exported ONNX checkpoint
python -m eval.benchmark_suite --runner local:/path/to/model

# Restrict to specific benchmarks
python -m eval.benchmark_suite \
    --runner bastionsoft/binary-bastion-prompt-protection-deberta-v3-xsmall-v1 \
    --benchmark rogue --benchmark jailbreakbench
```

## Single-benchmark mode

For quick smoke checks against one benchmark:

```bash
python -m eval.benchmark \
    --runner bastionsoft/binary-bastion-prompt-protection-deberta-v3-xsmall-v1 \
    --dataset rogue
```

## Layout

| File | Role |
|---|---|
| `data.py` | Loaders for each held-out benchmark from the Hugging Face Hub |
| `metrics.py` | AUC, F1, precision, recall, FPR at chosen TPR |
| `runners.py` | `BastionRunner` (local SDK) and `TransformersRunner` (any HF model id) |
| `benchmark_suite.py` | Multi-runner × multi-benchmark grid |
| `benchmark.py` | Single-runner, single-benchmark CLI |
| `results/leaderboard.json` | Latest published numbers (committed snapshot) |
